# Endpoints de reservas

Referencia de la superficie de reservas de `vivla-api`. Todas las rutas son **v2** (`/v2/...`); no hay prefijo global.

<Note>
  **La superficie `/v1` se eliminó.** Los controllers de reservas y calendario v1 ya no existen; toda la operación pasa por los controllers v2 (`admin` / `apps` / `tools`). La columna **Acceso** distingue la **app del copropietario** (usuario autenticado) del **panel** (protegido por `PermissionGuard` + `@RequirePermission(...)`); el permiso exacto va entre paréntesis.
</Note>

## App del copropietario

`src/bookings/v2/apps/bookings.apps.controller.ts` · path `bookings`, versión 2.

| Método | Ruta | Qué hace |
|--------|------|----------|
| GET | `/v2/bookings/my-stays` | Reservas de disfrute del usuario autenticado. |
| GET | `/v2/bookings/my-rents` | Reservas de alquiler del usuario. |
| GET | `/v2/bookings/my-exchanges` | Reservas de intercambio del usuario. |
| GET | `/v2/bookings/to-rent` | Reservas publicadas para alquilar dentro de la red. |
| GET | `/v2/bookings/to-exchange` | Reservas publicadas para intercambio. |
| GET | `/v2/bookings/:id` | Detalle de una reserva. |
| POST | `/v2/bookings/book` | Crea una reserva de disfrute. |
| PUT | `/v2/bookings/:id/request-rent` | Solicita el alquiler de una reserva publicada. |
| PUT | `/v2/bookings/:id/exchange` | Solicita el intercambio de una reserva publicada (gasta llaves). |
| POST | `/v2/bookings/exchange-last-hour` | Intercambio de última hora sobre un slot disponible. |
| POST | `/v2/bookings/stay/:id/update` | Actualiza la información de la estancia (ocupación, extras). |
| PUT | `/v2/bookings/:id/change` | Cambia el tipo de reserva (disfrute / intercambio / alquiler). |
| DELETE | `/v2/bookings/stay/:id/cancel` | Cancela una estancia (o anula la invitación si no eres el asistente principal). |
| DELETE | `/v2/bookings/:id/cancel` | Cancela la reserva. |
| GET | `/v2/bookings/:stayId/experiences` | Experiencias asociadas a una estancia. |
| POST | `/v2/bookings/:stayId/register-experience` | Registra (selecciona) una experiencia. |
| DELETE | `/v2/bookings/:stayId/remove-experience/:experienceSlug` | Deselecciona una experiencia. |
| GET | `/v2/bookings/keys/my-wallet` | Monedero de llaves propio (saldo). |
| GET | `/v2/bookings/keys/my-movements` | Movimientos de llaves propios (paginado por `page`). |

## Admin — panel CX (reservas y llaves)

`src/bookings/v2/admin/bookings.admin.controller.ts` · path `admin/bookings`, versión 2. Todos bajo `PermissionGuard`.

| Método | Ruta | Acceso | Qué hace |
|--------|------|--------|----------|
| GET | `/v2/admin/bookings` | `read:bookings` | Listado de reservas con filtros (`approval` entre ellos) y paginación. |
| GET | `/v2/admin/bookings/:id` | `read:bookings` | Detalle de una reserva. |
| POST | `/v2/admin/bookings/register` | `edit:bookings` | Registra una reserva manualmente (disfrute, alquiler, intercambio, ThirdHome). |
| POST | `/v2/admin/bookings/debug/register` | `edit:bookings` | Alta de reservas pasadas para depuración (no disponible en producción). |
| PUT | `/v2/admin/bookings/:id/edit` | `edit:bookings` | Modifica una reserva. |
| PUT | `/v2/admin/bookings/stay/:id/edit` | `edit:bookings` | Edita la estancia (fechas, notas, precio de alquiler). |
| POST | `/v2/admin/bookings/:id/add-stay` | `edit:bookings` | Añade la estancia con su asistente (inquilino/huésped). |
| POST | `/v2/admin/bookings/stay/:id/add-guest` | `edit:bookings` | Añade un invitado a la estancia. |
| PUT | `/v2/admin/bookings/stay/:id/main-guest` | `edit:bookings` | **(Nuevo)** Cambia el asistente principal de una reserva de disfrute (`ENJOY`), si no ha empezado. |
| DELETE | `/v2/admin/bookings/stay/:id/remove` | `edit:bookings` | Retira una estancia. |
| DELETE | `/v2/admin/bookings/guest/:guestId/remove` | `edit:bookings` | Retira un invitado. |
| DELETE | `/v2/admin/bookings/:id/cancel` | `edit:bookings` | Cancela la reserva. |
| POST | `/v2/admin/bookings/keys/:userId/register-movement` | `edit:exchanges` | Registra un movimiento manual de llaves. |
| GET | `/v2/admin/bookings/keys/movements` | `read:exchanges` | Listado de movimientos (filtros y paginación). |
| GET | `/v2/admin/bookings/keys/wallets` | `read:exchanges` | Listado de monederos. |
| GET | `/v2/admin/bookings/keys/charts` | `read:exchanges` | Datos para gráficas (`period`). |
| GET | `/v2/admin/bookings/keys/metrics` | `read:exchanges` | Métricas de llaves (`from`, `to`). |

<Note>
  **Los endpoints dedicados de v1 ya no existen.** `publish-third-home`, `unpublish-third-home`, `exchange-third-home`, `:id/rent`, `rent/approve`, `:id/liberate`, `add-referral-bonus`, `keys/transfer`, `pending-exchanges`, etc. se retiraron. Esas operaciones se hacen ahora con `register` / `:id/edit` / `add-stay` y el estado de aprobación `BookingApproval`. El **coste en llaves por casa** se fija ahora desde el módulo Properties: `POST /v2/admin/properties/:homeId/set-keys`.
</Note>

## Calendario

App en `src/calendars/v2/apps/calendars.apps.controller.ts` (path `calendars`); admin en `src/calendars/v2/admin/calendars.admin.controller.ts` (path `admin/calendars`). Ambos versión 2.

| Método | Ruta | Acceso | Qué hace |
|--------|------|--------|----------|
| GET | `/v2/calendars/available-bookings/:homeId` | App | Estancias disponibles del usuario en esa casa, por temporada. |
| GET | `/v2/calendars/property/:id` | App | Calendario de una casa (slots con disponibilidad, temporada, coste en llaves y marca de última hora). |
| GET | `/v2/admin/calendars` | `read:calendars` | Calendarios de reservas con filtros. |
| GET | `/v2/admin/calendars/types` | `read:calendars` | Tipos de calendario. |
| GET | `/v2/admin/calendars/:id/seasons` | `read:calendars` | Temporadas de un calendario. |
| GET | `/v2/admin/calendars/:id/slots` | `read:calendars` | Slots de un calendario. |
| POST | `/v2/admin/calendars/:id/slots/create` | `edit:calendars` | Crea un slot. |
| PUT | `/v2/admin/calendars/slot/:id/update` | `edit:calendars` | Modifica un slot. |
| DELETE | `/v2/admin/calendars/slot/:id/delete` | `edit:calendars` | Elimina un slot. |
| GET | `/v2/admin/calendars/owner/:id/available-stays/:homeId` | `read:calendars` | Estancias disponibles de un propietario en una casa. |
