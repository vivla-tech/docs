Esta wiki expone un servidor [MCP](https://modelcontextprotocol.io): un endpoint que cualquier asistente compatible (Claude, Cursor, VS Code Copilot…) puede consultar para buscar y leer la documentación de Vivla en tiempo real.

Una vez conectado, ya no hace falta copiar y pegar contenido al chat. Puedes preguntar cosas como:

- *"Según la wiki, ¿cómo se despliega el panel?"*
- *"Búscame en la wiki la guía de onboarding del bot de Slack."*
- *"¿Qué repos están en producción según `repositories`?"*

<Note>
  La URL del MCP es **`https://wiki.vivla.com/mcp`**. La primera vez, tu cliente abre el navegador para que inicies sesión con **Vivla Identity**, tu cuenta `@vivla.com`. No necesitas ninguna clave.
</Note>

## Cómo funciona el login

La wiki es privada: la protege Cloudflare Access. El MCP usa OAuth, así que tu cliente gestiona el login solo:

1. Añades la URL `https://wiki.vivla.com/mcp` en tu cliente.
2. El cliente abre el navegador con la pantalla de login de Vivla Identity.
3. Entras con tu cuenta de Google `@vivla.com`.
4. El cliente guarda el token y lo renueva cuando caduca. No tienes que repetir el login cada vez.

Solo pueden entrar cuentas `@vivla.com`.

## Instalación por herramienta

<Tabs>
  <Tab title="Claude Code">
    Ejecuta este comando en tu terminal:

    ```bash
    claude mcp add --transport http vivla-docs https://wiki.vivla.com/mcp
    ```

    Dentro de Claude Code, ejecuta `/mcp`, elige `vivla-docs` y pulsa **Authenticate**. Se abre el navegador para el login.

    Verifica que aparece conectado con:

    ```bash
    claude mcp list
    ```

    A partir de ahí, Claude Code puede usar las tools `search_vivla_docs` y `query_docs_filesystem_vivla_docs` cuando le preguntes sobre la wiki.
  </Tab>

  <Tab title="Claude Desktop / claude.ai">
    1. Abre **Settings → Connectors**.
    2. Pulsa **Add custom connector**.
    3. Rellena:
       - **Name:** `vivla-docs`
       - **URL:** `https://wiki.vivla.com/mcp`
    4. Pulsa **Connect** e inicia sesión con tu cuenta `@vivla.com`.
    5. Activa el conector cuando quieras que Claude lea la wiki.
  </Tab>

  <Tab title="Cursor">
    Abre la paleta de comandos (`Cmd+Shift+P`) → **Open MCP settings** → añade en `mcp.json`:

    ```json
    {
      "mcpServers": {
        "vivla-docs": {
          "url": "https://wiki.vivla.com/mcp"
        }
      }
    }
    ```

    En **Settings → MCP**, pulsa **Login** junto a `vivla-docs` e inicia sesión en el navegador.
  </Tab>

  <Tab title="VS Code (Copilot / MCP)">
    Crea `.vscode/mcp.json` en la raíz del workspace:

    ```json
    {
      "servers": {
        "vivla-docs": {
          "type": "http",
          "url": "https://wiki.vivla.com/mcp"
        }
      }
    }
    ```

    Al arrancar el servidor, VS Code te pide permiso para iniciar sesión. Acepta y entra con tu cuenta `@vivla.com`.

    También puedes ponerlo en tu config de usuario para tenerlo en todos los proyectos.
  </Tab>
</Tabs>

## Cómo usarlo

Una vez conectado, basta con mencionar la wiki en tu prompt y la IA usará el MCP por su cuenta. Ejemplos reales:

<CardGroup cols={2}>
  <Card title="Buscar contexto" icon="magnifying-glass">
    *"Antes de proponer una solución, busca en la wiki cómo está montada nuestra infra de Railway."*
  </Card>
  <Card title="Onboarding" icon="rocket">
    *"Soy nuevo en el equipo de panel: léete las páginas relevantes de la wiki y resúmeme la arquitectura."*
  </Card>
  <Card title="Cross-reference" icon="link">
    *"¿Hay alguna página en la wiki sobre cómo manejamos las notificaciones push?"*
  </Card>
  <Card title="Verificar antes de actuar" icon="shield-check">
    *"Antes de tocar este endpoint, comprueba en la wiki si hay una guía de cómo deprecarlos."*
  </Card>
</CardGroup>

## Para servicios y agentes (sin navegador)

Un servicio en servidor (por ejemplo, un agente en Railway) no puede hacer el login en el navegador. Usa un **service token** de Cloudflare Access y manda estas cabeceras en cada petición:

```text
CF-Access-Client-Id: <id>
CF-Access-Client-Secret: <secret>
```

Pide el service token al equipo de tech. Nunca lo pongas en el código ni en esta wiki: guárdalo como variable de entorno.

## Troubleshooting

<AccordionGroup>
  <Accordion title="No me aparece la tool en Claude / Cursor">
    Reinicia el cliente. Algunos clientes solo cargan los MCPs al arrancar. En Claude Code, ejecuta `claude mcp list` para confirmar que el servidor está registrado y conectado.
  </Accordion>
  <Accordion title="Error 401 o «needs authentication»">
    El cliente aún no tiene token. Lanza el login otra vez: en Claude Code, `/mcp` → `vivla-docs` → **Authenticate**. En los demás clientes, desconecta y vuelve a conectar el servidor.
  </Accordion>
  <Accordion title="El login me rechaza">
    Solo entran cuentas `@vivla.com`. Comprueba que eliges esa cuenta de Google y no una personal.
  </Accordion>
  <Accordion title="El asistente no usa el MCP aunque está instalado">
    Sé explícito en el prompt: *"Usa el MCP de la wiki de Vivla para buscar X"*. Algunos modelos solo usan tools cuando ven una señal clara de que las necesitan.
  </Accordion>
</AccordionGroup>
