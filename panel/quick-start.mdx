# Inicio rápido

Guía para arrancar el Panel en tu máquina por primera vez.

## Requisitos previos

- **Node.js** y **Yarn** instalados
- Acceso al repo [vivla-tech/vivla-panel](https://github.com/vivla-tech/vivla-panel)
- Los valores de Auth0 y Sentry para tu `.env.localdev` (pídelos al equipo)
- Tu cuenta de Google de Vivla con roles en el tenant de desarrollo de Auth0

## Instalación

```bash
git clone git@github.com:vivla-tech/vivla-panel.git
cd vivla-panel
yarn install
cp env.template .env.localdev
```

## Variables de entorno

Edita `.env.localdev` con tus valores:

```env
VITE_APP_ENV=localdev
VITE_API_BASE_URL=http://localhost:3000
VITE_AUTH0_CLIENT_ID=...
VITE_AUTH0_DOMAIN=...
VITE_AUTH0_AUDIENCE=...
VITE_SENTRY_DSN=...
```

Todas se validan al arrancar con Zod (`src/config/env.ts`). Si falta una obligatoria, la app falla al cargar.

| Variable | Obligatoria | Para qué |
| --- | --- | --- |
| `VITE_APP_ENV` | Sí | `localdev`, `staging` o `prod` |
| `VITE_API_BASE_URL` | Sí | URL base de `vivla-api` |
| `VITE_AUTH0_DOMAIN`, `VITE_AUTH0_CLIENT_ID`, `VITE_AUTH0_AUDIENCE` | Sí | Login contra Auth0 |
| `VITE_SENTRY_DSN` | No | Envío de errores a Sentry |
| `VITE_PUBLIC_POSTHOG_TOKEN`, `VITE_PUBLIC_POSTHOG_HOST` | No | Analytics con PostHog. No vienen en `env.template` |
| `SENTRY_ORG`, `SENTRY_PROJECT`, `SENTRY_AUTH_TOKEN` | No | Subida de sourcemaps en builds de staging y prod. En local no hacen falta |

<Tip>
  Para apuntar a la API local de Vivla, levanta `vivla-api` en `localhost:3000` antes de arrancar el panel.
</Tip>

## Arrancar el servidor de desarrollo

```bash
yarn dev
```

El panel queda disponible en `http://localhost:5173`.

<Warning>
  Auth0 solo acepta volver del login a `http://localhost:5173/login`. Si Vite arranca en otro puerto porque el 5173 está ocupado, el login falla con **Callback URL mismatch**. Libera el puerto o pide que añadan el tuyo a la app del panel en Auth0.
</Warning>

### Otros modos

| Comando | Entorno |
| --- | --- |
| `yarn dev` | localdev (API local) |
| `yarn dev --mode staging` | staging |
| `yarn dev --mode prod` | producción |

## Builds

| Comando | Resultado |
| --- | --- |
| `yarn build:local` | Build con envs de localdev |
| `yarn build:staging` | Build para staging |
| `yarn build:prod` | Build para producción |
| `yarn preview` | Sirve el build localmente |

## Calidad de código

```bash
yarn lint
```
