## Descripción

El módulo **Booking** gestiona la creación, visualización y cancelación de reservas. Soporta tres tipos de operación: reserva directa, intercambio y alquiler.

- **Ubicación:** `src/modules/booking/`

<Note>
  Los usuarios visitantes y aquellos sin propiedades registradas solo tienen acceso a la pantalla de
  alquiler (`RentScreen`).
</Note>

## API Endpoints

| Método   | Path                              | Descripción                             |
| -------- | --------------------------------- | --------------------------------------- |
| `GET`    | `/v2/bookings/{id}`               | Detalle de una reserva                  |
| `GET`    | `/v2/homes/{id}`                  | Propiedad asociada a reserva            |
| `POST`   | `/v2/bookings/stay/{id}/update`   | Actualizar datos de la estancia         |
| `POST`   | `/v1/bookings/{id}/reviews`       | Enviar reseña                           |
| `POST`   | `/v2/bookings/book`               | Crear reserva (por slots V2)            |
| `PUT`    | `/v2/bookings/{id}/request-rent`  | Crear reserva de alquiler               |
| `PUT`    | `/v2/bookings/{id}/exchange`      | Crear reserva de intercambio            |
| `POST`   | `/v2/bookings/exchange-last-hour` | Intercambio de última hora              |
| `DELETE` | `/v2/bookings/{id}/cancel`        | Cancelar reserva                        |
| `DELETE` | `/v2/bookings/stay/{id}/cancel`   | Cancelar la propia estancia (asistente) |
| `PUT`    | `/v2/bookings/{id}/change`        | Modificar tipo de reserva               |

## Hooks

| Hook                                     | Descripción                                           |
| ---------------------------------------- | ----------------------------------------------------- |
| `useBooking(bookingId, propertyId)`      | Fetch de reserva y propiedad                          |
| `useCancelBooking()`                     | Cancelar con invalidación de cache                    |
| `useModifyBooking()`                     | Modificar tipo de reserva                             |
| `useBookingDetail(bookingId)`            | Detalle de una reserva                                |
| `useBookingReviews()`                    | Enviar reseña                                         |
| `useCreateBooking()`                     | Crear reserva directa                                 |
| `useCreateBookingToRent()`               | Crear reserva de alquiler                             |
| `useCreateBookingToExchange()`           | Crear reserva de intercambio                          |
| `useCreateBookingToExchangeLastHour()`   | Intercambio última hora                               |
| `useBookingUpdate({ enableAutoUpdate })` | Autoguardado con _debounce_ del formulario de reserva |

      tipo `enjoy` sin estancia permanecen en `APPROVED`.

## Queries

<Warning>
  Todas las consultas de reservas utilizan **React Query** (`bookingQueries`) para fetching y
  caching. No realizar llamadas directas al API fuera de este sistema de queries.
</Warning>

El módulo define `bookingQueries` con claves de cache estructuradas para:

- Listado de reservas del usuario
- Detalle de reserva individual
- Propiedades asociadas
- Invalidación automática tras mutaciones (crear, cancelar, modificar)
