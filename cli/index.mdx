---

`vivla` deja lista tu máquina y los repos de `vivla-tech` que te tocan: clona, instala la versión de Node de cada uno, baja los `.env` de Vercel o Railway (nunca de producción) y configura las skills y los MCP de Claude Code, Cursor y Codex. Después sirve para el día a día: qué hay desplegado, logs, Supabase, migraciones, PRs y releases. Lo usan igual las personas (con un asistente en la terminal) y los agentes (con `--json` o por MCP).

## Instalar

```bash
npm i -g github:vivla-tech/vivla-cli   # deja el comando vivla
vivla                                  # asistente: login, tus repos, plan e instalación
```

O sin instalar nada: `npx --yes github:vivla-tech/vivla-cli`.
